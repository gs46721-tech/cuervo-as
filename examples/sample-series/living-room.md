# Sample set: living room

Asset `bg_living_room` version 1.0.0. Location id `loc_living_room`. One set, reused by every shot in the reference scene.

## Stage

Pixel space. Origin on the floor at center. +x right, +y up. The camera looks at the couch wall.

| Piece | Asset | Placement |
| --- | --- | --- |
| Couch | `prop_couch` | Centered, seat line at y = 40. Left cushion x = -180. Right cushion x = 180. |
| Coffee table | `prop_coffee_table` | In front of the couch, toward the camera, x = 0. |
| Television | `prop_television` | On the wall behind the couch, camera-right of center. It is off. |
| Remote | `prop_remote` | Under the left cushion. Not visible. Pinned so the line about it has an asset. |
| Lamps | part of the background plate | One at each end of the couch. Both on. |
| Doorway | part of the background plate | Camera-left, closed. |
| Window | part of the background plate | Camera-right, evening outside. |

## Approved framing for this set

`wide`, `two_shot`, `over_the_shoulder`, `close_up`, `reaction`, `insert`.

The reference scene uses `wide`, `two_shot`, and `close_up`. The other presets are legal for a later shot in this room and are not required in the 32-second scene.
